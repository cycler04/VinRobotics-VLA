# Qwen Specialized Robot Models

The detailed Qwen robot-specialist research is split into two independent reports:

| Model | Scope | Report |
| --- | --- | --- |
| **Qwen-RobotManip** | Cross-embodiment manipulation, 80-D action representation, flow-matching DiT, training data, VLA/VL batch mixing, and manipulation evaluations | [Qwen-RobotManip report](qwen_robotmanip.md) |
| **Qwen-RobotNav** | Waypoint navigation, task-adaptive observation encoding, trajectory/VL sampling, configuration randomization, and navigation evaluations | [Qwen-RobotNav report](qwen_robotnav.md) |

For the generalist model, see [Qwen-VLA](qwen_vla.md). Qwen-RobotWorld is outside this
index because it predicts future visual states rather than robot actions or navigation waypoints.

> **Research date:** 2026-07-22. The reports use Qwen-RobotManip v2 and
> Qwen-RobotNav v3. Results are author-reported and have not been reproduced in this
> workspace.
